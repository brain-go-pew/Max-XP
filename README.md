## Project Purpose

This repository is the team’s shared workspace for the **Stage 2 Markdown V2.0 assignment**. Its purpose is to hold the complete, checked learning content for the **AI Overview** module — the shared foundation for the module’s:

- Study Guide
- PPT Slides
- Video Tutorials
- Test Bank

In Stage 1 we established the module structure and demonstrated our teaching approach through selected developed content. In Stage 2 we developed **all core topics in scope** into a substantially complete, checked foundation. Version 2.0 is not a plan — it contains the actual learning material, including accurate beginner-friendly explanations, definitions of unfamiliar terms, worked examples, useful visuals, learner activities with checked answers, key takeaways, and identifiable references.
